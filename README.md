# yphone

一个把角色、对话和日常应用放进同一台虚拟手机里的前端项目。

🔗 **在线体验：<https://yphone.pages.dev>**

桌面、锁屏、通讯录、消息、世界书、钱包、音乐和相册都各自有状态，并在同一个本地存档里协同工作。它不是聊天窗口的外壳，而是一套围绕角色互动展开的浏览器内虚拟设备。

项目不提供账号体系，也不把角色卡、聊天记录、世界书或图片上传到项目服务器。AI 请求由浏览器直接发送到你在设置中填写的接口；接口地址、Key 和模型由使用者自己决定。

## 有什么

### 虚拟手机壳

- 虚拟桌面、锁屏、状态栏、底部 Home Bar 和多页应用布局
- 壁纸、锁屏壁纸、桌面图标、桌面小组件和外观设置
- 支持拖动图标、调整页面布局、配置锁屏快捷入口
- 锁屏密码、支付密码、通知、音效、震动和减弱动效等设置
- 可作为 PWA 添加到手机主屏幕，使用方式接近一台独立的小设备

### 角色与对话

- 通讯录管理角色，支持新建、编辑、搜索和删除
- 支持导入 PNG、JSON、DOCX、TXT、Markdown 等格式的角色卡
- 角色卡中的名称、简介、性格、场景、示例对话和开场白可整理到对应字段
- 支持单人聊天、群聊、消息记录、未读状态、消息重试和上下文管理
- 每个角色可以拥有独立的人设、关系、称呼、生日、年龄段和 MBTI
- 支持兴趣、自我介绍、互动边界、角色动态、朋友圈内容和长期记忆
- 支持从聊天中给角色点外卖、买礼物，以及让角色参与日常场景

### 人设与世界书

- 人设面具：为“我”保存多套身份设定，并指定不同角色使用哪一套
- 人设包含称呼、性别、年龄段、关系、MBTI、生日、兴趣、自我介绍和雷区
- 世界书以关键词触发设定卡，不把所有背景资料固定塞进每一次请求
- 支持破限、文风、人设、世界观、剧情、状态等分类
- 支持常驻条目、启停、排序、角色专属世界书和角色是否读取世界书
- 支持导入与导出 JSON，也支持把文本文件整理成世界书条目
- 聊天过程中可以查看本轮实际命中的世界书条目，便于检查设定是否生效

### AI 接口

- 兼容 OpenAI Chat Completions 格式的接口
- 可填写 API 地址、API Key 和模型名称
- 支持从接口读取模型列表
- 支持独立配置图片生成、图片编辑接口和模型
- 支持生成图片、编辑图片和让角色发送图片
- 内置接口监视：记录请求次数、耗时、模型、输入输出 token 和错误信息
- 没有配置接口时，普通的桌面、备忘录、日历、计算器等本地功能仍可使用

### 日常应用

| 应用 | 内容 |
| --- | --- |
| **备忘录** | 创建、编辑、删除本地备忘录，桌面小组件可以显示最近内容 |
| **时钟** | 时钟、计时器与状态显示 |
| **日历** | 月视图、日期和日程记录，支持桌面与锁屏显示 |
| **相册** | 查看本地保存的图片、角色生成图片和聊天中的媒体内容 |
| **音乐** | 导入音乐链接或本地音乐，播放器在切换应用时保持状态 |
| **计算器** | 基础计算功能 |
| **通讯录** | 角色卡、角色搜索、编辑和发起对话 |
| **世界书** | 关键词触发的设定卡管理 |
| **我的人设** | 管理自己在不同对话中的身份设定 |
| **外观** | 壁纸、锁屏、图标布局和视觉设置 |
| **设置** | AI 接口、导入导出、通知、音效、密码和数据管理 |

### 外卖、商城与钱包

- 外卖商家和商品可以由 AI 根据场景生成，也有无接口时的基础兜底数据
- 支持点餐、购物车、收货地址、订单状态和订单记录
- 桃桃商城支持商品浏览、分类、搜索和购买
- 外卖与商城共用同一个钱包余额和收货地址簿
- 支持给自己下单，也支持在聊天中给角色点外卖或购买礼物
- 付款前先扣款，余额不足时订单不会成立
- 可设置独立的支付密码，与锁屏密码分开管理

## 数据与隐私

默认情况下，数据保存在当前浏览器的本地：

- `localStorage` 保存设置、角色、消息、世界书、备忘录、日历、订单和应用数据
- IndexedDB 保存较大的图片和媒体资源，避免把图片直接塞进 `localStorage`
- 不需要注册账号，不依赖项目后端
- AI 请求从浏览器直接发出，项目不会代为转发或托管 API Key
- 浏览器数据按域名隔离；换设备、换浏览器或清除站点数据后，本地内容不会自动恢复
- 使用设置中的导出功能定期保存 JSON 备份，需要换设备时再导入

建议在修改浏览器数据、清理缓存或迁移设备前，先导出一份存档。图片资源和结构化数据的保存方式不同，迁移时应使用项目提供的导出功能，而不是只复制 localStorage。

## 使用

直接打开 `index.html` 即可运行，也可以使用在线版本：

<https://yphone.pages.dev>

首次使用 AI 对话或 AI 生成内容时，在「设置」中填写：

1. API 地址
2. API Key
3. 模型名称

填写完成后，可以先使用“拉取模型列表”确认接口可用，再进入聊天或其他 AI 应用。API 是否支持图片生成、图片编辑和模型列表，取决于所填写的服务。

手机上可以通过浏览器菜单选择“添加到主屏幕”。项目本身没有登录页，也没有必须安装的客户端。

## 技术实现

- 原生 HTML、CSS、JavaScript
- 无框架、无构建步骤，静态文件可直接部署
- 使用 IIFE 组织模块，避免脚本级变量互相污染
- 通过 `window.SJ` 暴露数据层，通过 `window.APPS` 注册应用，通过 `window.SHELL` 管理应用栈
- 使用 `localStorage` 保存主要结构化数据
- 使用 IndexedDB 保存较大的图片资源
- 使用内联 SVG 图标，不依赖外部图标库
- 使用 Web App Manifest 提供 PWA 安装信息
- 使用浏览器原生 API 处理文件导入、通知、音频、图片和本地存储
- 静态文件可部署到 Cloudflare Pages，当前在线版本为 <https://yphone.pages.dev>

### 本地运行

直接双击 `index.html` 可以打开基础界面。涉及模块、媒体、PWA 或浏览器安全策略的功能，建议使用静态服务器：

```bash
python -m http.server 8080
```

然后打开：

<http://localhost:8080>

项目不要求 Node.js，也没有 npm 安装步骤。

## 关于 API Key

API Key 由浏览器直接用于请求你填写的接口，并保存在当前浏览器的本地设置中。不要在公共电脑上保存个人 Key，也不要把包含 Key 的浏览器存档分享给其他人。

如果接口地址允许跨域请求，浏览器才能直接访问；如果服务端没有配置 CORS，聊天、模型列表或图片功能可能无法使用。这属于接口服务端配置，不是项目后端代理可以自动解决的问题。

---

## 已知限制

- 数据默认只存在当前设备和当前浏览器，项目没有账号同步
- 不同浏览器、不同设备之间不会自动共享角色、消息和图片
- AI 功能依赖用户提供的接口、Key、模型和 CORS 配置
- 浏览器对本地存储容量、音频自动播放、通知权限和文件访问权限有各自限制
- 图片和媒体资源比普通文本更占空间，长期使用应定期导出或清理
- 外卖、商城和部分角色动态内容在未配置 AI 时使用本地兜底逻辑，内容不会与真实服务同步
